# SmartVoyage 启动文档

## 1. 环境准备

- Python 3.10 及以上
- MySQL，默认连接：`127.0.0.1:3306`，数据库 `travel_rag`
- DeepSeek API Key

## 2. 首次启动

在项目根目录打开 PowerShell，依次执行：

```powershell
# 创建并启用虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt

# 创建本地配置
Copy-Item .env.example .env
```

根据 `.env.example` 填写 `.env` 中所需的 API Key。该文件包含私人配置，不应提交到 GitHub。

如使用非默认 MySQL，请在 `.env` 中配置项目支持的 `MYSQL_*` 环境变量。

首次使用或数据库为空时，初始化表和示例数据：

```powershell
python script/init_session_tables.py
python script/init_ticket_mock_data.py
python script/init_trip_mock_data.py
```

## 3. 启动服务

```powershell
python main.py
```

浏览器访问：<http://127.0.0.1:8000>

## 4. 常见问题

- 提示依赖缺失：确认已启用 `.venv`，然后重新执行 `pip install -r requirements.txt`。
- 数据库连接失败：检查 MySQL 是否运行，以及 `.env` 中的 `MYSQL_*` 配置。
- 端口被占用：关闭占用 `8000` 端口的程序，或修改 `main.py` 中的 `port`。
